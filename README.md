# ControlPanel

Локальная панель управления проектами для одного рабочего компьютера. Она
собирает в одном интерфейсе список проектов, их состояние, открытые порты,
системные метрики, логи, историю действий и базовую web-аналитику.

## Возможности

- Вход в локальную панель и журналирование действий.
- Каталог проектов с путём, группой, URL, портами и доступными действиями.
- Запуск, остановка и перезапуск заранее разрешённых npm-, Docker Compose- и
  `.bat`-сценариев.
- Проверка доступности локальных портов и состояния управляемых процессов.
- Метрики компьютера: загрузка CPU, память, диск и uptime.
- Хранение метрик, истории действий и событий в локальной SQLite-базе.
- Просмотр логов и добавление новых проектов через интерфейс.

## Стек

React и Vite для интерфейса; Express и Node.js для локального API; SQLite для
метрик, событий и журнала действий.

## Локальный запуск

```bash
npm install
npm run dev
```

Клиент запускается на `http://127.0.0.1:5179`, API — на
`http://127.0.0.1:8787`. Для production-сборки интерфейса используйте
`npm run build`, а для запуска API — `npm start`.

## Важно о безопасности

Это локальный инструмент, а не готовая публичная админ-панель. Значения в
`.env.example` предназначены только для разработки. Перед любым удалённым
доступом необходимо задать уникальные `PANEL_EMAIL`, `PANEL_PASSWORD` и
`PANEL_TOKEN_SECRET`, ограничить доступ на сетевом уровне и настроить HTTPS.
Не публикуйте `.env`, базу `data/panel.sqlite` или логи.

Подробности безопасного удалённого доступа через Cloudflare находятся в
[CLOUDFLARE_REMOTE_ACCESS.md](CLOUDFLARE_REMOTE_ACCESS.md).
